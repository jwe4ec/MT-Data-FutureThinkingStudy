# MT-Data-FutureThinkingStudy

This repository is the knowledge base for the MindTrails Future Thinking Study 
(Templeton) dataset. For more information about the Future Thinking Study, see 
the [Future Thinking page][mt-wiki-ft] of the [MindTrails wiki][mt-wiki].
